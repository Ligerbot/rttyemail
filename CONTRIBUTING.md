# How to contribute to the code

Run `git pull` before changing the code to make sure it is up to date.

First make your changes to the code. Then, when you are ready run `git add .` from the top level directory.

Next, run `git commit -m "Your message here"` then finally run `git push`.

It should prompt you to open a browser window and make a pull request. Just write a description of what you changed.
